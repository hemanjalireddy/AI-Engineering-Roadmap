## 💡 Why Open Source?

I believe in **learning in public** and contributing to the community. By sharing my learning journey openly, I hope to:

- **Help others** who are on the same path - see what resources worked for me
- **Stay accountable** - documenting publicly keeps me motivated
- **Get feedback** - others can suggest better resources or point out mistakes
- **Build a portfolio** - showcase my learning progress and projects
- **Give back** - I've learned so much from free resources, time to contribute back
